# 제출 직전 체크리스트

1. `README.md`의 `<YOUR_GITHUB_ID>`와 `[ID]`를 본인 GitHub 아이디로 수정
2. 아래 명령으로 테스트하고 결과가 `OK`인지 확인
   ```bash
   python3 -m unittest discover -s tests -v
   ```
3. GitHub에 **Public** 저장소 `tiny-secondhand-secure` 생성 후 업로드
4. 보고서의 `[XX반]`, `[이름]`, `[0000]`, GitHub URL 수정 후 PDF 저장
5. PDF 파일명을 `[WHS][secure-coding][XX반]이름(0000).pdf`로 변경하고 공백이 없는지 확인
6. GitHub 저장소에 `.db`, 실제 비밀번호, 개인정보가 올라가지 않았는지 확인
7. LMS에 PDF 제출 후 GitHub 링크가 열리는지 다시 확인
